# Kai's Birthday Universe ✦

A multi-section, animated birthday website for **Kai (Aditya)**, built with plain HTML, CSS, and JavaScript. No build tools or package installation required.

## Features

- Deep-space theme, animated starfield, orbiting planet, glow effects
- Responsive layout for mobile, tablet, and desktop
- Scroll reveal animations and number counters
- Personal birthday letter and wishes
- Bible blessing from Numbers 6:24–25, plus additional verses
- Interactive make-a-wish button with confetti
- Surprise modal with one final message
- Optional ambient tone (only starts after the visitor clicks Sound)
- Reduced-motion accessibility support

## Run locally

1. Download and unzip the project.
2. Open `index.html` in your browser.

For a local development server, you can use VS Code's Live Server extension or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `kai-birthday`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site. The URL will look like `https://YOUR-USERNAME.github.io/kai-birthday/`.

## Personalize it

Search `index.html` for `Kai`, `Aditya`, or the birthday message to adjust the wording. The theme colors and animation styles are near the top of `style.css`.

Everything runs client-side; there is no form submission or personal data collection.
